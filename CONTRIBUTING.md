# Contributing

Ten Billion Lives is currently a local-first MVP. GitHub issues and milestones define scope and dependency order; read `AGENTS.md`, `README.md`, `docs/PRODUCT.md`, and the issue you intend to address before changing code.

Keep each contribution issue-scoped and reviewable. Add the cheapest test that can falsify the behavior, implement the smallest coherent change, and run focused checks before the documented root local check. User-facing work needs real-browser inspection; determinism and conservation changes need explicit replay or invariant evidence.

Do not add servers, networking, CI, Pages, containers, deployment, cloud services, runtime paid APIs, or work labeled `phase:deferred` during the local-MVP phase. Do not weaken tests or broaden the product claim.

By participating, you agree to follow `CODE_OF_CONDUCT.md`. Contributions are accepted under the MIT License.
